## 0. PURPOSE

Dokumen ini mendefinisikan TAMPILAN VISUAL SEDERHANA (wireframe) untuk
setiap state visual di LOGIC_FLOW.txt v1.0:
- Struktur elemen (apa saja yang tampil)
- Hierarki & posisi (di mana)
- Interaksi visual (apa yang bisa di-hover / di-click)
- Alur visual E2E (dari boot sampai quit)

Dokumen ini TIDAK membahas:
- Warna, font, ukuran exact, easing → DESIGN.md
- Nilai pixel final, timing animation exact, dimensi window exact → TDD
- Kode/CSS → implementasi

Filosofi: Wireframe = "apa yang tampil dan di mana". BUKAN "bagaimana
tampilannya (cantik atau tidak)".

## 1. DESIGN PRINCIPLES (wireframe level, bukan visual)

| # | Principle | Konsekuensi Wireframe |
|---|-----------|-----------------------|
| P1 | Notch harus terasa "ringan" dan menyatu dengan atas layar | Posisi top-center, jarak dari tepi atas minimal |
| P2 | Expand harus jelas, tidak ambigu | Ada perubahan ukuran & konten yang nyata |
| P3 | Setiap elemen interaktif punya visual affordance | Tombol terlihat seperti tombol |
| P4 | Tidak ada informasi palsu (battery, dsb. di V1) | Idle state hanya jam/ikon |
| P5 | Pin state harus jelas terlihat | Pin indicator selalu terlihat saat S4 |
| P6 | First-run tooltip sekali pakai | Ada mekanisme dismiss (klik/ESC/auto-hide) |

## 2. GLOBAL LAYOUT

Posisi & layering (semua wireframe):
┌─────────────────────────── SCREEN (primary monitor) ──────────────────────────┐
│ │
│ ┌──────────────┐ │
│ │ CAPSULE │ ← top-center │
│ └──────────────┘ ← Y offset (default: kecil) │
│ │
│ (desktop / apps / work) │
│ │
└────────────────────────────────────────────────────────────────────────────────┘

text

- Anchoring: horizontal center, vertical = top edge + offset (configurable).
- Window: frameless, transparent, always-on-top, skipTaskbar.
- Z-index: selalu di atas window normal; tidak di atas fullscreen app (V1 limit).
- Focus: window TIDAK mengambil fokus saat expand / click (U3).

### WIREFRAME 1 — S1: IDLE_COLLAPSED
**Mapping:** LOGIC_FLOW S1
**Kapan:** Default state, tidak ada hover, tidak pinned, tidak first-run.
┌──────────────────┐
│ ♪ │ ← ikon status (media / no media)
└──────────────────┘
(kapsul kecil, ref: ~180 x 32)

text

**Elemen:**
| ID | Element | Konten | Interaksi |
|----|---------|--------|-----------|
| E01 | Capsule container | bentuk kapsul | hover → expand; click → pin |
| E02 | Status icon | ikon `♪` jika ada media; ikon `•` atau clock-mini jika tidak | (tidak interaktif) |

**Interaksi:**
- Hover capsule → transisi ke S2 (jika media) atau S3 (jika tidak).
- Click capsule → transisi ke S4.
- Tidak ada animasi terus-menerus (U4).

**Tidak tampil di sini:** title, artist, tombol kontrol, pin indicator, tooltip.

---

### WIREFRAME 2 — S2: EXPANDED_MEDIA
**Mapping:** LOGIC_FLOW S2
**Kapan:** Hover di S1, ada session media aktif.
┌──────────────────────────────────────────────┐
│ [icon] Spotify [pin] │ ← row 1: source + pin affordance
│ │
│ ◀◀ ▶/⏸ ▶▶ Song Title │ ← row 2: controls + track info
│ Artist Name │
└──────────────────────────────────────────────┘
(ref: ~320 x 80)

text

**Elemen:**
| ID | Element | Konten | Interaksi |
|----|---------|--------|-----------|
| E01 | Capsule container | expand | hover out → S1 (jika tidak pinned); click → S4 |
| E02 | Status icon | ikon app sumber (Spotify/Edge/VLC) | (tidak interaktif) |
| E03 | Source app label | string "Spotify" / "Edge" / dll | (tidak interaktif) |
| E04 | Pin affordance (idle) | ikon pin outline | (visual cue saja; klik capsule = pin) |
| E06 | Prev button | ikon `◀◀` | click → IPC `prev` |
| E07 | Play/Pause button | ikon `▶` atau `⏸` (sesuai status) | click → IPC `play_pause` |
| E08 | Next button | ikon `▶▶` | click → IPC `next` |
| E04a | Track title | text, truncated 1 baris | (tidak interaktif) |
| E05 | Track artist | text, truncated 1 baris | (tidak interaktif) |

**Interaksi:**
- Hover out (dengan debounce 150–200ms) → S1.
- Click capsule (bukan tombol) → S4 (pin).
- Click tombol kontrol → kirim IPC, JANGAN ubah state visual (kecuali play/pause mengubah ikon E07).
- Klik tombol tidak collapse ke S1 meskipun mouse keluar sesaat.

**Catatan layout:** E03 (source) + E04a (title) + E05 (artist) adalah teks; harus punya truncation rule (ellipsis). Rule final di DESIGN.md.

### WIREFRAME 3 — S3: EXPANDED_EMPTY
**Mapping:** LOGIC_FLOW S3
**Kapan:** Hover di S1, TIDAK ada media; ATAU session berakhir saat expanded.
┌──────────────────────────────────────────────┐
│ [pin] │
│ │
│ 14:32 │ ← jam (atau ikon minimalis)
│ │
└──────────────────────────────────────────────┘
(ref: ~320 x 80)

text

**Elemen:**
| ID | Element | Konten | Interaksi |
|----|---------|--------|-----------|
| E01 | Capsule container | expand | hover out → S1; click → S4 |
| E04 | Pin affordance (idle) | ikon pin outline | visual cue |
| E10 | Clock display | jam (HH:MM), update per menit | (tidak interaktif) |

**Interaksi:**
- Sama seperti S2 untuk hover out dan pin.
- Tidak ada tombol kontrol (karena tidak ada media).
- Transisi dari S2 → S3 (session hilang) harus < 300ms, tanpa error mentah (U5).

**Non-elements (eksplisit dilarang di V1):** battery indicator, CPU usage, weather, dsb.

### WIREFRAME 4 — S4: PINNED_EXPANDED
**Mapping:** LOGIC_FLOW S4
**Kapan:** User klik capsule dari S2 atau S3. State "dipin" — tidak collapse saat mouse leave.

**4A — S4 dengan media (dari S2 → pin):**
┌──────────────────────────────────────────────┐
│ [icon] Spotify [pin●] │ ← pin terisi (aktif)
│ │
│ ◀◀ ▶/⏸ ▶▶ Song Title │
│ Artist Name │
└──────────────────────────────────────────────┘

text

**4B — S4 tanpa media (dari S3 → pin):**
┌──────────────────────────────────────────────┐
│ [pin●] │
│ │
│ 14:32 │
│ │
└──────────────────────────────────────────────┘

text

**Elemen (tambahan/delta dari S2 & S3):**
| ID | Element | Konten | Interaksi |
|----|---------|--------|-----------|
| E09 | Pin indicator (active) | ikon pin filled | click → unpin (kembali ke S2/S3 lalu S1) |

**Interaksi:**
- Mouse leave → TIDAK collapse (beda dari S2/S3).
- ESC → collapse + unpin → S1.
- Click capsule (di luar tombol) → unpin → transisi ke S2 atau S3 (sesuai media state), lalu ke S1 (dengan debounce).
- Click tombol kontrol → kirim IPC, tetap di S4.

**Catatan:** S4 memenuhi UX Contract U1 (user selalu tahu cara dismiss: ESC / klik pin / klik capsule).

---

### WIREFRAME 5 — S5: FIRST_RUN_TOOLTIP
**Mapping:** LOGIC_FLOW S5
**Kapan:** Hanya sekali saat first launch (config: first_run = true). Setelah dismiss, tidak muncul lagi.
┌─────────────────────────────────────┐
│ Hover to expand · Click to pin · │
│ ESC to close │
└──────────────────┬──────────────────┘
▼
┌──────────────────┐
│ ♪ │
└──────────────────┘

text

**Elemen:**
| ID | Element | Konten | Interaksi |
|----|---------|--------|-----------|
| E11 | Tooltip bubble | teks singkat, max 2 baris | click bubble → dismiss |
| E12 | Tooltip arrow | panah ke capsule | (tidak interaktif) |
| E01 | Capsule (di bawah tooltip) | sama seperti S1 | tetap interaktif |

**Interaksi:**
- Klik di mana saja pada tooltip / capsule → dismiss (set first_run = false, persist).
- ESC → dismiss.
- Auto-hide setelah 5 detik.
- Setelah dismiss → S1 (tidak muncul lagi sampai user reset config manual).

**Aturan konten:** teks harus ≤ 2 baris, ≤ 60 karakter per baris. Isi final di DESIGN.md (bukan wireframe).

## 4. VISUAL JOURNEY E2E (dari boot sampai quit)
[BOOT]
│
▼
S0 BOOT (non-visual: single-instance check, load config, spawn SMTC, tray)
│
├─ first_run == true ──▶ S5 (tooltip) ──[dismiss]──▶ S1
│
└─ first_run == false ─▶ S1 (collapsed)
│
├─ hover ─┬─ ada media ─▶ S2 (expanded media)
│ └─ no media ─▶ S3 (expanded empty)
│
├─ click ─▶ S4 (pinned: S4A atau S4B)
│ │
│ ├─ ESC ─▶ S1
│ ├─ click pin ─▶ S2/S3 ─▶ (debounce) ─▶ S1
│ └─ mouse leave ─▶ STAY (tidak collapse)
│
├─ (S2/S3) mouse leave + debounce ─▶ S1
│
├─ (S2/S3/S4) media session ends ─▶ S3 atau S1
├─ (S2/S3/S4) media session baru ─▶ S2 (update)
│
├─ tray → Hide ─▶ S6 (non-visual)
│ └─ tray → Show ─▶ S1
│
└─ tray → Quit / Ctrl+Q ─▶ S7 (non-visual, persist, exit)
│
▼
[EXIT]

S8 (soft error) = internal fallback, tidak terlihat sebagai state visual.

text

## 6. INTERACTION MAP (rangkuman)

| Aksi user | State | Efek visual | IPC / Logic |
|-----------|-------|-------------|-------------|
| Hover capsule | S1 | expand → S2/S3 | (lokal) |
| Mouse leave capsule | S2, S3 | collapse → S1 (debounce 150–200ms) | (lokal) |
| Click capsule (di luar tombol) | S1 | pin → S4 | (lokal) |
| Click capsule (di luar tombol) | S2, S3 | pin → S4 | (lokal) |
| Click capsule (di luar tombol) | S4 | unpin → S2/S3 → (debounce) S1 | (lokal) |
| Click tombol Prev | S2, S4A | tidak berubah state | `prev` |
| Click tombol Play/Pause | S2, S4A | ikon toggle | `play_pause` |
| Click tombol Next | S2, S4A | tidak berubah state | `next` |
| Click pin indicator | S4A, S4B | unpin → S2/S3 → (debounce) S1 | `toggle_pin(false)` |
| ESC | S4 | collapse → S1 | `toggle_pin(false)` |
| Klik tooltip / capsule | S5 | dismiss → S1 | set first_run=false |
| Tray → Hide | any | window hidden (S6) | `hide_window` |
| Tray → Show | S6 | window shown → S1 | (lokal) |
| Tray → Quit / Ctrl+Q | any | persist + exit (S7) | `quit_app` |

**Aturan visual:** semua transisi state visual harus menggunakan properti
GPU-accelerated (transform/opacity). Detail easing & durasi di DESIGN.md.
